# General Settings

**Platforms:** Old Reddit and New Reddit · **Always on**

General Settings holds cross-module preferences that affect the overall Toolbox-NXG experience.

## Overview

These settings apply globally across all modules. They cover the overall look, notification delivery style, and the behaviour of the context menu that appears when Toolbox shows new activity.

## Settings

| Setting                       | Default | Description                                                                       |
| ----------------------------- | ------- | --------------------------------------------------------------------------------- |
| Classic look                  | Off     | Make Toolbox look like Toolbox 6.x; see [Classic look](#classic-look) below       |
| Native notifications          | On      | Show OS-level notifications instead of in-page banners                            |
| Context menu location         | Left    | Which side of the screen the context menu slides in from                          |
| Context menu attention effect | Open    | How the context menu signals new items: open automatically, fade in, or no effect |
| Context menu click to open    | Off     | Require a click to open the context menu instead of opening on hover              |

## Classic look

For moderators coming from Toolbox 6.x, the classic look restores the familiar appearance:

- Square corners on windows, buttons, inputs and popups.
- A single small shadow under raised surfaces, in place of the deeper drop shadows.
- General buttons with 6.x's left accent bar, grey text and smaller type.
- 6.x's dark mode: when Reddit (or RES night mode, or your operating system) is dark, colors are an inverted version of the light theme, as in 6.x, rather than Toolbox-NXG's own dark palette.

The colors in light mode are the same either way - Toolbox-NXG's light palette is 6.x's. The setting takes effect immediately, on old and new Reddit alike.
