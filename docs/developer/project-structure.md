| `images/`         | Extension icons and static images                                                             |
| `modules/`        | Individual feature modules (one directory per module)                                         |
| `modules/shared/` | Cross-module subsystems (proposals, usernotes, modnotes, removal reasons, settings, etc.)     |
| `shared/`         | Shared React building blocks: app root (`app/`), controls (`controls/`), windows (`window/`)  |
| `store/`          | Redux Toolkit store: settings and cross-component UI feedback (spinner, toasts, context menu) |
| `types/`          | Ambient type declarations (CSS modules, untyped dependencies)                                 |
| `util/`           | Pure utility functions (data, infra, persistence, reddit, ui, wiki)                           |

## Module layout

Each module under `extension/data/modules/<name>/` follows the layered structure described in [Module Architecture](module-architecture.md).

## How API requests authenticate

Every Reddit API call goes from the content script to the background script, which sends it to `oauth.reddit.com` (see `makeRequest` in `background/handlers/webrequest.ts`). Reddit accepts different credentials on different endpoints, so each request picks one:

- **Reads** (`GET`/`HEAD`) start with the session cookie and no `Authorization` header. Classic endpoints such as `/api/info.json` answer 403 to any request carrying a bearer token.
- **Bearer-only reads** start with an OAuth bearer token instead: everything under `/api/mod/` and `/api/v1/`, plus the flair template lists (`/r/<sub>/api/user_flair_v2` and `link_flair_v2`). `/api/v1/me` answers a cookie-only request with the logged-out shape, and the flair template lists answer it with 404, so neither can rely on the fallback below.
- **Fallback:** a read refused with **403** is retried once under the other mode. A refusal with any other status, such as 404, is not retried, which is why endpoints that refuse that way have to be listed as bearer-only.
- **Mutations** (`POST`/`DELETE`) always use a bearer token and are never retried, so an action is never performed twice.
- **Redirects** are refused (`redirect: 'error'`), so an endpoint that answers with a redirect (such as `/about/sticky`) always fails; read the data from another endpoint instead.

The rule lives in `initialOAuthMode` in `webrequest.ts`. When Reddit changes which credentials an endpoint accepts, `scripts/auth-probe.js` shows it: paste it into the extension's service worker console while logged in as a moderator, with `sub` set to a subreddit you moderate. It requests every GET Toolbox sends under cookie, bearer and both, and prints a second table that replays `initialOAuthMode` (plus the 403 fallback) and marks each endpoint `ok` or `BROKEN` with the reason. It sends only GETs, plus two harmless POSTs: the read-only `flairselector`, and unsaving a nonexistent post. When you add an API call, add its endpoint to the probe; the probe copies `initialOAuthMode`'s lists, so change the two together.
